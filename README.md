### 🚀 Standalone Products & Tooling ([@kleinbem-dev](https://github.com/kleinbem-dev))

Reusable open-source tools and platforms built for community and production use:

- **[cadre](https://github.com/kleinbem-dev/cadre)** — Private AI teammates on your own compute, powered by Goose over local inference (Ollama, Mesh-LLM).
- **[revue](https://github.com/kleinbem-dev/revue)** — Nix-native AI PR code review engine with subscription fallback (Claude, Gemini, Ollama) and Forgejo support.
- **[attic-ui](https://github.com/kleinbem-dev/attic-ui)** — Next-generation web UI and binary store inspector for Attic Nix binary caches.
- **[nix-gantry](https://github.com/kleinbem-dev/nix-gantry)** — CI builds once; hosts fetch a manifest and atomically swap in a NixOS/systemd-nspawn container without on-host evaluation.
- **[nix-detour](https://github.com/kleinbem-dev/nix-detour)** — Safe detour mechanism for Nix packages: hold broken unstable packages or run open upstream nixpkgs PRs until merged.
- **[foyer](https://github.com/kleinbem-dev/foyer)** — Lightweight homelab portal and service launchpad for modern fleet setups.
