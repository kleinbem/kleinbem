# AGENTS.md

Always-on guidance for AI assistants in the kleinbem fleet workspace. `CLAUDE.md`, `GEMINI.md`
and `.goosehints` are symlinks to this file; edit it in `kleinbem/root/`. It loads in every
session, so it stays short: fleet orientation (conductors, what each repo is for, every `just`
recipe, where IaC goes) is in the `kleinbem-fleet` skill, jj detail in `jj-workflow`, builds,
CI and CodeRabbit in `agent-ops`.

## Where you are

`~/Develop/github.com/kleinbem/` is not a repo. It holds about 30 independent sibling git+jj repos,
listed in `kleinbem/repos.nix`. `cd` into the repo you work on; each has its own `AGENTS.md`.
For hosts, services, storage, network or secrets wiring, read `INFRASTRUCTURE.yaml` here first
(generated by `just dev::sync-agent` in nix-config).

## Work in your own jj workspace

The primary checkout `<repo>/` is Martin's. jj snapshots `@` on nearly every command, so two
sessions in one working copy silently move or drop each other's edits, and sessions that finish
there leave commits and bookmarks behind.

```bash
just jj::ws-new <repo> [name]              # <repo>.ws/<name>/ on main: cd there, then work
just jj::ws-new <repo> <name> -r <change>  # move existing work out of the primary checkout
just jj::ws-list [filter]                  # open workspaces and their @ state
just jj::ws-gc [filter]                    # reap empty ones after the PR merged
```

- Claim the workspace before reading or editing the repo. Workspaces have no `.git`: use jj.
- Finish from the workspace: describe, push, open the PR. After the merge, `just jj::ws-gc` and
  `just pull-all` clean up. `just clean` (from the root) checks that nothing was left behind.

## VCS and pull requests

- jj first (colocated with git). Raw `git` only for rescue.
- Every default branch requires signed commits. jj signs with the YubiKey's no-touch key.
- Every PR auto-merges: right after `gh pr create`, run `gh pr merge --auto --squash`. Public
  repos also require the CodeRabbit check and resolved conversations, so answer every CodeRabbit
  thread before walking away. Open a draft when a change must be held.
- To bring a PR up to date use `gh pr update-branch` without `--rebase`: GitHub's rebase drops
  signatures.

## Code comments

A comment says why the code is this way, in 1–3 lines. History ("was X, replaced with Y"),
dates, debugging stories and alternatives tried go in the commit message or PR body, not the
file. Keep real gotchas, short. When you edit near a long comment, shorten it too.

## Secrets

`kleinbem-secrets` holds the fleet's sops + age secrets. Never assume a plaintext file in any
`*-secrets` repo is safe to read, edit or reference: verify first.

## Environment

Each repo's `.envrc` loads a Nix devshell (`nix-devshells#workspace` or a domain shell) with
`just`, `jj`, `gh`, `sops`, `age` and the fleet tools. If one seems missing, check
`direnv status` / `direnv allow` before installing anything.
